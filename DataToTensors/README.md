# Data To Tensors

This series of notebooks tries to explore how to examine a machine learning problem, identify the data and how to format it.

Start with [ProblemToModelMarimo.py](ProblemToModelMarimo.py) to get a basic overview of how to break down the problem and ask questions about your data and problem domain.

Then look at [DataToTensorsMarimo.py](DataToTensorsMarimo.py) to get more insight into the shape and form of your data.

Note this has been written in conjunction with an LLM (codex and claude) to bounce ideas and formatting / examples to be used.
